Remote control of BB for a trusted orchestrator (Grok Bot, Executor) through a code-mode MCP.

`bb_execute` runs JavaScript in an isolated worker with a `bb` global mirroring the complete BB SDK (generated from its declarations) — threads including plugin metadata and context usage, projects, environments, files, terminals, hosts including machine providers, providers, plugins, system including synced UI preferences, skills, threadSections, theme, desktop browsers and guide — plus `bb.ops` for durable, deduplicated dispatch receipts (spawns and forks it records are seeded with `{ operationId }` in the thread's `bb-mcp` metadata namespace) and `bb.approve` for remote permission approvals. `bb_read` exposes the same surface restricted to non-mutating methods, annotated read-only so clients can auto-approve it. Compose calls, loop, wait and filter inside the worker; only the final result crosses the wire.

The endpoint grants the plugin's owner-level access over `x-bb-plugin-token` authentication with Host/Origin checks. This is a trusted-caller remote interface — the worker is a reliability boundary, not a security sandbox — protect the token accordingly.
