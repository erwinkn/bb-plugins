Add optional provider icons through bb's public Plugin SDK. A source-controlled
mapping accepts exact provider IDs from the live catalog, including IDs outside
ACP. The included Devin entry keeps the Devin CLI mark and name.

The settings page shows provider IDs and names. Icons have accessible labels and
tooltips. The compact model picker stays under bb's control; this plugin does not
add permanent text beside each tab. Custom ACP display names can be previewed and
applied through an explicit CLI command. Install and reload do not change agent
settings.

Edit the mapping in Git and install a rebuilt revision. This personal plugin
does not provide an agent, collect credentials, or contact an image service.
