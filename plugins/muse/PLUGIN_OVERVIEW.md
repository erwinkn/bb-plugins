Run Meta's Muse Code in bb: Muse Wonder and Spark models with reasoning
levels, streamed answers, shell, file and web rows, bb's tools inside Muse,
approvals and questions in bb's UI, and Muse's subscription windows in the
usage popup.

## What you get

- A **Muse** provider in the picker. Threads resume across restarts, take
  steering mid-turn, stop cleanly and compact on `/compact`.
- bb's tools (Adventures, chat memory, plans, questions, …) callable from Muse.
- Permission modes mapped to Muse's profiles: Full runs unsandboxed, Auto lets
  Muse's AI reviewer decide, Accept edits asks for anything beyond the
  workspace.

## Requirements

Muse Code installed and signed in (`muse login`) on each machine that runs
Muse threads. The bridge finds `muse` on PATH or in `~/.local/bin`.
