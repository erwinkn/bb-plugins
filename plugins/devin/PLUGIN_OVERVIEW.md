Run Devin CLI inside bb with a native provider icon and name, sign-in guidance,
an executable setting, and the models available through your Devin account.

The plugin uses bb's public ACP bridge. Install Devin CLI and sign in on the
machine where your threads run. Authentication stays with Devin; the plugin
does not copy login credentials.

The provider ID remains `acp-devin`. If you already configured Devin as a custom
ACP agent, migrate that entry before enabling this provider. Only one plugin can
own the ID. Existing icon-only plugins can then be disabled.

This is a personal integration, not an official Cognition plugin.
