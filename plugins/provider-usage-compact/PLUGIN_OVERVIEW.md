Open the chart icon in the sidebar footer to see provider usage for your selected
machine. The header leaves room for provider tabs, including Devin when its
provider reports usage support.

## Controls

The machine icon opens a menu with machine names and connection states. Hover
over the icon to see the current machine name. The refresh button loads usage
again. Extra provider tabs wrap onto another row when space is limited.

Use the arrow keys, Home, and End to select a provider. Click outside the popup
or press Escape to close it. Usage bars retain plan labels, reset times, costs,
and warning indicators reported by BB.

## Requirements

Requires BB 0.42.1 or later and installed providers with usage support. Providers
use their existing sign-in details. No separate account or API key is required.
Disable the built-in Provider usage plugin after installing this replacement.
You can enable it again at any time.
